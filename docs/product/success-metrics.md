# 成功指标 · D8 · 青蚨使

- Status: accepted（与 PRD 同步）
- Date: 2026-08-22
- 约束：ADR 001–004；产品：`docs/product/prd.md`

## 北极星

**「主理人放心拍」率**：在 dogfood 周期内，完成「提议→确认→执行」且主理人主观评分 ≥4/5（事后问卷或周记）的笔数占比。

- 定义边界：仅计真实确认笔（含 Mock 轨演示笔，须标注环境）；静默路径必须为 0（硬门禁，不进北极星公式）。

## Leading（领先，周频查看）

| 指标 | 定义 | V1 目标 | 反指标 |
|------|------|---------|--------|
| 无人确认扣款笔数 | `execute` 时提案非 `approved` 的次数 | **恒为 0** | 任何 >0 = 发布阻断 |
| 提议→确认中位耗时 | 自 `proposed` 至 `approved|rejected|cancelled` | dogfood ≤ 24h；CLI 当场确认 ≤ 5min | 中位 >7 天且堆积 proposed |
| 契约测试绿 | 未确认不可执行、冻结不可提议、退款状态机 | 主分支 100% 绿 | 跳过/删除门禁测试 |
| 三端垂直切片可演示 | CLI / MCP / Web 各自完成至少 1 条 P0 路径 | 按 stage-spec DoD | 「半截端」合入 main |

## Lagging（滞后，双周/月看）

| 指标 | 定义 | V1 目标 | 反指标 |
|------|------|---------|--------|
| Dogfood 确认笔数 | 主理人真实点允准的笔数（002） | 4 周内 ≥20 或满 4 周周记 | 0 笔却宣称可用 |
| 审计取证成功率 | 随机抽 5 笔能导出完整事件链 | 100% | 缺事件/对不上状态 |
| 退款请求闭环率 | `refund` 调用有终态 `refunded|refund_failed` | 100%（含 rail_unsupported） | 请求无状态 |
| 开源理解信号 | 有效 Issue/PR 讨论领域语言 | 首发后 30 天 ≥1（Aspiration） | 仅星标无讨论（信息项） |
