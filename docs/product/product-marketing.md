# Product Marketing Context · 青蚨使

Document version: 1.0.0  
Changelog: 2026-08-22 — 初稿（审计闭合 ⑤）

## Product

- **Name:** 青蚨使 / Qingfu Envoy  
- **One-liner:** 开源 Agent 付款控制面——提议、你确认、再走支付宝等持牌通道。  
- **Category:** Agentic payment control plane（非支付牌照机构）

## Audience / ICP

- **ICP:** 个人开发者与独立创造者，使用 AI Agent 办事且需真实付款。  
- **JTBD:** 让 Agent 把付款提议清楚呈上，我确认后才扣款，并能审计与退款请求。  
- **Anti-persona:** 要「额度内静默代扣」的无人值守资金盘；要自建清算的持牌诉求方。

## Positioning

- **For** 个人开发者  
- **Who** 不敢把扣款权交给不可见自动化  
- **Qingfu Envoy is** 可自托管的授节控制面  
- **That** 强制人确认并留下审计  
- **Unlike** 大厂封闭钱包内 Agent 付 / 纯协议规格  
- **We** 开源、挂你已有支付宝等通道、不做牌照生意  

## Competitive frame

见调研（非范围权威）；差异化：人确认默认、开源自托管、中文领域语言。

## Customer language

- 「提议 → 确认 → 付款」  
- 「急停」「审计导出」「退款请求」  
- 勿说「自动扣款」「免密代付」为卖点（001）
