# 001 — 无牌照；前期禁止静默自付

- Status: accepted
- Date: 2026-08-22（产品边界拍板）
- 相关：[ROADMAP.md](../../ROADMAP.md) 当前状态

## Context

青蚨使定位为个人开发者可开源的 Agent 支付控制面。持牌方（支付宝 / 微信 / 银行）负责实际资金搬运。行业存在「额度内静默自付 / L3–L4 条件自主」能力，若前期引入，在算法与意图确认不可靠时会放大误付与信任崩塌风险。

## Decision

- **不做支付牌照业务**：不自建清算 / 收单主体；扣款执行一律走已有持牌通道。
- **前期禁止静默自付**：在算法 / 意图确认机制被明确验证之前，不提供「边界内无人确认即扣款」。
- **前期默认路径**：提议 → 人确认 → 再调用支付宝 / 微信 / 银行完成付款；配合审计可见与急停 / 取消未决。
- **边界外**：牌照申请、赔付基金、额度内全自动扣款均不在本阶段范围。

## Consequences

- 正面：合规边界清晰；产品可开源演示；与用户「不能闭眼」诉求一致。
- 负面：体验不如大厂「授额即走」爽；需反复强调人机确认的价值叙事。
- 后续：静默自付若启用，须另开 ADR（前置：意图确认算法与验收标准已接受）。
